# Transx Logistics — Website

Website for a logistics and freight company.

**Live demo:** https://elvinbaxsh.github.io/Transx-Logistics/

## Features

- Pages: Home, Services (freight), Contact
- **Language switcher:** page text changes without reloading, using JavaScript language files
- Responsive layout

## Tech Stack

HTML · CSS · JavaScript

## Getting Started

No build step needed. Open `index.html` in a browser.
